# zstack

zstack is a modified copy of [pstack](https://github.com/cursor/plugins/tree/main/pstack).

## Install

Claude Code:

```bash
claude plugin marketplace add zieksef/agent-plugins
claude plugin install zstack@zieksef
```

Codex:

```bash
codex plugin marketplace add zieksef/agent-plugins
codex plugin add zstack@zieksef
```

## Zen-mode

Start a task with zen-mode.

- In Claude Code, type `/zstack:zen-mode` and then the task, such as `/zstack:zen-mode fix the intermittent 500 on the login endpoint`.
- In Codex, type `$`, pick `zstack:zen-mode`, and then describe the task.
